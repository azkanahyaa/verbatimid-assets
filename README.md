# verbatimid-assets

Gambar publik untuk blog [verbatim.id](https://verbatim.id): featured image dan `og:image` artikel.

- Repo ini hanya titik ambil. CMS (Directus) mengimpor gambar dari URL `raw.githubusercontent.com`, lalu situs menyajikannya dari CMS.
- Isinya hanya aset yang memang tampil publik di situs. Jangan menaruh file internal, data responden, atau kredensial di sini.
- Konvensi nama: `blog/<slug-artikel>-featured-1200x630.png` (1200×630 px).
